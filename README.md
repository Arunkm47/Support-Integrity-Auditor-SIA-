# Support Integrity Auditor (SIA)

A machine learning system for detecting support ticket priority mismatches (Hidden Crisis / False Alarm).

## Features
- Rule-based pseudo-label generation
- DistilBERT binary classification
- Mismatch detection
- Hidden Crisis and False Alarm identification

## Model
- DistilBERT-base-uncased
- Binary Classification

## Metrics
- Accuracy
- Macro F1
- Recall

## Repository Structure

- Notebook.ipynb
- train_pipeline.py
- predict.py
- requirements.txt
- pseudo_labeled_dataset.csv
